# Airfare Price Estimation and Fare Pattern Analysis

## Project Overview
This project aims to estimate flight ticket prices using Machine Learning techniques and analyze the factors that influence airfare variations.

The system uses flight-related information such as source city, destination city, airline, journey date, departure time, duration, number of stops, and booking-related attributes to predict airfare.

## Problem Statement
Estimate airfare from route, airline, journey-date, duration, stop-count, and booking-related attributes. Compare regression algorithms, engineer date and categorical features, and analyze factors associated with higher fares. Evaluate on held-out records and explain how collection dates and market changes limit current-price predictions.

## Objectives
- Predict flight ticket prices using Machine Learning.
- Compare multiple regression algorithms.
- Perform date and categorical feature engineering.
- Analyze factors influencing airfare.
- Evaluate models using MAE, RMSE, and R².
- Develop a user-friendly airfare prediction interface.

## Algorithms
- Linear Regression
- Decision Tree Regression
- Random Forest Regression
- Additional regression algorithm for comparison

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- HTML, CSS, JavaScript
- FastAPI

## Expected Outcome
A Machine Learning-based web application that estimates airfare based on user-provided flight details and provides insights into airfare patterns.

## Disclaimer
Predictions are based on historical training data. Actual flight prices may vary depending on booking time, demand, availability, and market conditions.
