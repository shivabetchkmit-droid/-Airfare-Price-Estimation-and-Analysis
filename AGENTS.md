# AGENTS.md (pointer for AI coding agents)

This repo is **FareLens**, "Airfare Price Estimation and Fare Pattern Analysis" (Python/FastAPI + scikit-learn, vanilla JS frontend), built by a team of 4.

**Before doing anything, read in this order:**
1. `.agent/rules/project-rules.md`: mandatory rules (ownership boundaries, contracts, leakage and honesty rules)
2. `docs/HANDBOOK.md`: goals, requirement matrix R1-R7, feature IDs, architecture
3. `docs/CONTRACTS.md`: data schema, Python interface, REST API (source of truth for interfaces)
4. `docs/roles/ROLE_<n>_*.md`: the role of the person prompting you (ask if not stated)
5. `docs/DECISIONS.md`: earlier decisions

If something is unclear after reading these, **ask one concise question instead of guessing**. Never invent column names, API fields, or metrics. Stay inside the prompting user's role directories.
